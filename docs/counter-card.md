# Counter — keyboard card

Print this one page and tape it to the counter. Every key here works from the till screen
(`/pos/`) with the search box or nothing focused — no mouse required for a normal sale.

| Key | Action |
|---|---|
| Scan, or type a name/SKU/barcode then **Enter** | Add the item to the cart |
| **Enter** with the search box empty | Take an exact cash payment, print, and clear for the next sale |
| **↑ / ↓** | Move the highlighted line (cart, or the search-result list while it's open) |
| **F2** | Open the tender screen (cash, card, bKash, split, credit) |
| **F3** | Change the quantity of the selected line |
| **F4** | Discount the selected line, or override its price (if you're allowed to) |
| **F5** | Quick-add a product that isn't in the catalogue yet |
| **F6** | Attach a customer by phone number |
| **F7** | Hold (park) the current sale |
| **F8** | Resume a held sale |
| **F9** | Start a return or exchange against a past sale |
| **F10** | No-sale — open the drawer and print a slip without a sale (if you're allowed to) |
| **Esc** | Void the selected line; press again to void the whole cart |

Every one of these also works by clicking the matching button on screen — the keys are
the fast path once you know them, not the only path.

**Scanning** — a scan behaves exactly like typing the code and pressing Enter, so nothing here
changes when a real barcode scanner is used instead of the keyboard. If a scan lands in the wrong
text field (a note, a search box you were mid-type in), tab or click into the search box first —
the scanner has no way to know which field you meant.
